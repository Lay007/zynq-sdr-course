# Welcome to the Zynq SDR Course community

> **GitHub Discussions draft.** Publish this text in the repository's Announcements category and pin the discussion. This source file does not create a GitHub Discussion.

The [Zynq SDR Course](https://lay007.github.io/zynq-sdr-course/) is about taking a signal-processing idea from a mathematical model to a reproducible result in code, FPGA and, where appropriate, RF hardware.

This is a place to ask engineering questions, discuss design choices and share experiments with other learners and developers.

## Where to start

- **New to the course?** Follow the [student path](https://github.com/Lay007/zynq-sdr-course/blob/main/docs/student-path.md) or the [Getting Started Wiki](https://github.com/Lay007/zynq-sdr-course/wiki/Getting-Started).
- **Working on Zynq or AD936x?** Start with the [Hardware Wiki](https://github.com/Lay007/zynq-sdr-course/wiki/Hardware) and [Troubleshooting](https://github.com/Lay007/zynq-sdr-course/wiki/Troubleshooting).
- **Interested in the engineering evidence?** Review the [hardware evidence index](https://github.com/Lay007/zynq-sdr-course/blob/main/docs/hardware-evidence-index.md).
- **Found a reproducible bug or want to implement something?** Open an [Issue](https://github.com/Lay007/zynq-sdr-course/issues/new/choose). General questions belong here in Discussions.

## What makes a useful question or experiment report?

Include the block/lab, OS and tool versions, repository revision, expected and observed behavior, and what you already checked. For a physical RF experiment, document the frequency, gain, attenuation, sample rate and IQ metadata.

Please distinguish **simulation**, **fixed-point**, **RTL**, **FPGA** and **RF-measured** results. A waveform seen in simulation is not evidence that a board passed the same test.

Do not share passwords, access tokens, private configuration, personal information or proprietary IQ datasets. Report sensitive vulnerabilities privately using the [security policy](https://github.com/Lay007/zynq-sdr-course/blob/main/SECURITY.md).

## A first question for the community

**Which learning route are you using: laptop only, RTL-SDR, or Zynq/AD936x hardware?** It would be useful to hear what equipment you have, what you are trying to build and which lab you started with. You do not need any hardware to participate.

Thanks for helping make this course more useful for people who want to understand not only how an SDR algorithm works, but how to verify it.
