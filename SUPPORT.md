# Getting help

Use the shortest route that matches your question.

| Need | Where |
| --- | --- |
| Learn a concept or repeat a lab | [Course website](https://lay007.github.io/zynq-sdr-course/) and [student path](docs/student-path.md) |
| Find a quick answer or diagnosis | [Wiki FAQ](https://github.com/Lay007/zynq-sdr-course/wiki/FAQ) and [Troubleshooting](https://github.com/Lay007/zynq-sdr-course/wiki/Troubleshooting) |
| Report a reproducible bug, failed lab or broken link | [Issue templates](https://github.com/Lay007/zynq-sdr-course/issues/new/choose) |
| Propose a concrete change to teaching material or code | [Contributing](CONTRIBUTING.md) and a focused issue or pull request |
| Report a vulnerability, exposed secret or unsafe procedure with sensitive details | [Security policy](SECURITY.md): report privately |

## Questions versus issues

Learning questions, design tradeoffs and brainstorming belong in **GitHub Discussions** once the repository maintainer enables it. If Discussions is unavailable, consult the FAQ or open an issue **only** for a reproducible defect or a specific proposed improvement; please do not turn the bug tracker into a general help forum.

When asking for diagnostic help, share the relevant block/lab, environment and revision, what you expected, what you observed and what you already tried. For RF tests, include frequencies, gain and attenuation **without publishing sensitive credentials or private configuration**.

Answers in Discussions are useful context, but verified lab procedures and measurement results must be maintained in the versioned course documentation.
