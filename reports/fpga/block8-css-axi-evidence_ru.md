# CSS AXI-ускоритель блока 8: результаты реализации Vivado OOC

[English version](block8-css-axi-evidence.md)

## Результат

Vivado 2021.1 полностью маршрутизирует `css_sf7_axi_accelerator` в режиме OOC и
выполняет ограничение `100 МГц` для `xc7z020clg400-2`:

| Метрика | Post-route результат |
|---|---:|
| WNS / TNS | `+0.165 нс` / `0.000 нс` |
| Нарушенные endpoints | `0 / 3018` |
| Задержка критического пути | `9.712 нс` |
| Оценка по критическому периоду | `101.678 МГц` |
| Полностью разведённые сети | `2135 / 2135` |
| Ошибки routing / DRC | `0 / 0` |

Критический путь остаётся внутри последовательного DFT: от состояния индекса
отсчёта через distributed-память и арифметику DSP48 к регистру слагаемого.
Регистры результата AXI-Stream и control plane AXI-Lite не стали критическим
путём.

## Ресурсы

| Ресурс | Post-synthesis | Post-route | Доступно в XC7Z020 |
|---|---:|---:|---:|
| Slice LUT | 849 | 787 | 53 200 |
| Slice registers | 867 | 867 | 106 400 |
| BRAM tiles | 1.5 | 1.5 | 140 |
| DSP48E1 | 16 | 16 | 220 |

Относительно routed-результата изолированного детектора AXI-граница добавляет
156 LUT и 446 регистров, не меняя количество BRAM и DSP. Рост регистров в
основном создают удерживаемый 256-битный выходной пакет и снимок результата
AXI-Lite.

## Воспроизведение

Команда выполняется из корня репозитория в Windows:

```powershell
python tools/generate_block8_css_axi_vivado_reports.py
```

Повторная проверка существующих отчётов без нового запуска Vivado:

```powershell
python tools/generate_block8_css_axi_vivado_reports.py --reuse
```

Source-only flow создаёт проект в памяти, ограничивает `aclk` периодом
`10.000 нс` и выполняет synthesis, optimization, placement, physical
optimization и routing. Project, checkpoint, bitstream, log и journal не
сохраняются.

## Задержка и пропускная способность

RTL-регрессия подтверждает 16 644 такта от последнего принятого отсчёта до AXI
результата и 16 645 тактов до sticky status/IRQ AXI-Lite. При 100 МГц интервал
запуска символов остаётся равным 16 772 тактам, или 5 962.318 решения/с.

## DRC и ограничения доказательств

Финальный DRC не содержит нарушений уровня Error. Его 46 предупреждений
совпадают с OOC methodology findings изолированного детектора: 44 рекомендации
по конвейеру DSP48, одно предупреждение о ненагруженном внутреннем status и
ожидаемое предупреждение об отсутствии PS7. Для внешних OOC-портов потоков и
регистров не заданы I/O delays и `HD.PARTPIN_LOCS`.

Результат доказывает routed timing внутренних путей AXI RTL top-level, но не
полного Zynq block design. Пока отсутствуют PS7, AXI interconnect/DMA,
инфраструктура clock/reset, назначение адресов и ограничения платы; bitstream и
аппаратный тест не выполнялись.

Машиночитаемые метрики и нормализованные отчёты находятся в
`reports/fpga/block8_css_axi_vivado_ooc_raw/`.
