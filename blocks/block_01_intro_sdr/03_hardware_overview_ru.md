# 03. Аппаратная база курса

## Назначение раздела

Этот раздел знакомит с практическим SDR-стендом курса и объясняет, какой вклад каждый элемент оборудования вносит в общую инженерную цепочку:

**модель → FPGA / RF-фронтенд → внешний приёмник → запись IQ → офлайн-анализ**

## 1. Аппаратная база

В первом блоке используется компактный, но реалистичный SDR-стенд:

- SDR-плата **Zynq-7020 + AD9363**;
- внешний приёмник **RTL-SDR**;
- ПК для моделирования, наблюдения, записи и анализа;
- кабельный или эфирный радиоканал;
- при необходимости аттенюаторы, переходники и согласующие элементы.

## 2. RTL-SDR V3 Pro

![RTL-SDR V3 Pro](/zynq-sdr-course/images/hardware/rtl_sdr_v3_pro_real.png)

Приёмник RTL-SDR используется как внешний инструмент наблюдения. Он позволяет убедиться, что переданный сигнал существует за пределами основной SDR-платы и принимается независимым устройством.

**Роль в курсе:**

- первое обнаружение сигнала;
- наблюдение спектра и водопада в HDSDR;
- запись IQ для офлайн-анализа;
- практическая демонстрация усиления приёмника, шума и перегрузки.

## 3. Плата Xilinx Zynq-7020 + AD9363

![Xilinx Zynq-7020 с модулем ADRV](/zynq-sdr-course/images/hardware/xilinx_7020_adrv_real.png)

Это основная SDR-платформа курса на уровне платы. Она связывает цифровую обработку сигналов с реальным RF-фронтендом.

**Zynq-7020 даёт:**

- процессорную систему ARM для управления и конфигурации;
- программируемую логику FPGA для детерминированной потоковой обработки;
- практический мост между программными моделями и аппаратной реализацией.

**AD9363 даёт:**

- передающий и приёмный RF-тракты;
- преобразование ЦАП/АЦП;
- аналоговую фильтрацию и перенос частоты;
- интерфейс потока I/Q с цифровым трактом обработки.

## 5. Варианты соединения

### Через эфир

Преимущества:

- наглядная демонстрация;
- быстрая настройка;
- близко к реальной работе радиосистемы.

Ограничения:

- внешние помехи;
- хуже повторяемость;
- сильная зависимость от расположения антенн и обстановки.

### Через кабель

Преимущества:

- повторяемые измерения;
- контролируемый канал;
- проще сравнивать эксперименты между собой.

Ограничения:

- аттенюатор обязателен;
- прямое неконтролируемое соединение TX с RX опасно для приёмника;
- нужно соблюдать ограничения по уровню на входе.

## 6. Дисциплина уровней сигнала

Никогда не соединяйте передатчик напрямую с приёмником, не понимая уровней сигнала.

Всегда учитывайте:

- максимально допустимый уровень на входе;
- аттенюацию;
- потери в кабелях;
- усиление приёмника;
- признаки ограничения (clipping) и перегрузки.

## 7. Чек-лист перед лабораторной

Перед первой лабораторной убедитесь, что:

- SDR-плата правильно запитана;
- ПК видит RTL-SDR;
- выбранный радиоканал безопасен;
- HDSDR показывает спектр приёмника;
- подготовлено место для записи IQ;
- параметры эксперимента записаны.

## 8. Инженерный вывод

На первом этапе стенд намеренно простой, но он уже содержит полный инженерный цикл SDR:

**генерация → передача → приём → наблюдение → запись → анализ → улучшение**

Это основа для следующих блоков: модуляции, синхронизации, fixed-point реализации, обработки в FPGA и RF-измерений.
