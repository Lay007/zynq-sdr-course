# Лабораторная 6.1 — Частотный план RF-эксперимента

## Цель

Научиться заранее рассчитывать, где должен появиться тестовый сигнал в спектре приёмника с учётом TX LO, RX LO и цифрового смещения.

## Что выполняется

В работе студент:

1. выбирает частоты TX и RX гетеродинов;
2. задаёт цифровой offset тестового тона;
3. рассчитывает ожидаемое положение сигнала в baseband;
4. проверяет условие Найквиста;
5. оценивает частотную ошибку по измеренному пику.

## Результат

После выполнения работы должны быть получены:

- таблица частотного плана;
- ожидаемый baseband offset;
- проверка полосы наблюдения;
- расчёт frequency error;
- вывод о корректности RF-настройки.

## Что приложить к отчёту

- TX/RX center frequencies;
- sample rate и RF bandwidth;
- digital tone offset;
- expected observed offset;
- measured peak frequency;
- инженерный вывод.

## Подробная техническая часть
### Практический вопрос

> Где должен появиться полезный сигнал в спектре приёмника и как взаимодействуют частота дискретизации, частота LO и цифровое смещение?

### Базовая частотная модель

```mermaid
flowchart LR
    BB[Смещение тона в основной полосе] --> TXLO[LO TX]
    TXLO --> RF[RF-сигнал]
    RF --> RXLO[LO RX]
    RXLO --> IF[Наблюдаемое смещение в основной полосе]
```

Если передатчик использует центральную частоту `f_tx` и генерирует цифровой тон со смещением `f_bb`, RF-тон появляется на частоте:

```text
f_rf = f_tx + f_bb
```

Если центральная частота приёмника — `f_rx`, наблюдаемое смещение в основной полосе приблизительно равно:

```text
f_observed = f_rf - f_rx
```

Следовательно:

```text
f_observed = f_tx + f_bb - f_rx
```

### Пример плана

| Параметр | Значение | Комментарий |
|---|---:|---|
| Центральная частота TX | 915 МГц | LO TX AD9363 |
| Центральная частота RX | 915 МГц | центр RTL-SDR/HDSDR |
| Смещение цифрового тона | +100 кГц | формируется FPGA/DSP |
| Ожидаемое наблюдаемое смещение | +100 кГц | пик должен появиться на +100 кГц |
| Частота дискретизации | 2,4 МС/с | полоса наблюдения |
| RF-полоса | 2 МГц | полоса аналогового тракта |

### Варианты частотного плана

| Случай | LO TX | Цифровое смещение | LO RX | Ожидаемое наблюдаемое смещение |
|---|---:|---:|---:|---:|
| Одинаковый LO | 915 МГц | +100 кГц | 915 МГц | +100 кГц |
| RX сдвинут вверх | 915 МГц | +100 кГц | 915,05 МГц | +50 кГц |
| RX сдвинут вниз | 915 МГц | +100 кГц | 914,95 МГц | +150 кГц |
| Отрицательный тон | 915 МГц | −100 кГц | 915 МГц | −100 кГц |

### Проверка наложения и полосы

Ожидаемое наблюдаемое смещение должно находиться внутри диапазона Найквиста приёмника:

```text
|f_observed| < Fs_rx / 2
```

Для `Fs_rx = 2,4 МС/с`:

```text
|f_observed| < 1,2 МГц
```

Добавьте запас на аналоговые фильтры и несовершенства приёмника. Не размещайте тестовый тон слишком близко к краю полосы.

### Практическая процедура

1. Выберите законную и безопасную для вашей лаборатории тестовую частоту.
2. Выберите LO TX и LO RX.
3. Выберите небольшое смещение цифрового тона, например 50–200 кГц.
4. Убедитесь, что ожидаемое смещение находится внутри полосы приёмника.
5. Начните с малого усиления TX и внешнего ослабления.
6. Посмотрите на спектр.
7. Запишите фактическую частоту пика.
8. Оцените частотную ошибку.

### Частотная ошибка

```text
frequency_error = measured_peak - expected_peak
```

Возможные причины:

- ошибка частоты LO;
- смещение опорного генератора приёмника;
- ошибка частоты дискретизации;
- разрешение бина FFT;
- ошибки в соглашении о знаке;
- перестановка IQ или сопряжение.
