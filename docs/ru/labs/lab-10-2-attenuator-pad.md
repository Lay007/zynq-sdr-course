# Лабораторная 10.2 — Простой аттенюатор

## Цель

Научиться рассчитывать простую цепь ослабления сигнала и понимать, почему аттенюатор обязателен в RF/SDR loopback-экспериментах.

## Что выполняется

В работе студент:

1. выбирает требуемое ослабление;
2. рассчитывает делитель напряжения;
3. переводит отношение напряжений в дБ;
4. анализирует влияние нагрузки;
5. формулирует ограничения учебного аттенюатора.

## Результат

После выполнения работы должны быть получены:

- расчёт номиналов;
- ожидаемое ослабление;
- схема подключения;
- safety conclusion для SDR-стенда.

## Подробная техническая часть
### Инженерный вопрос

> Как безопасно уменьшить уровень сигнала перед приёмником SDR или измерительным входом?

### Основная идея

Аттенюатор уменьшает амплитуду сигнала и защищает чувствительные входы от перегрузки или повреждения. В экспериментах SDR ослабление обязательно для прямого кабельного loopback TX–RX.

### Простой делитель напряжения

```text
Vout = Vin * R2 / (R1 + R2)
```

Ослабление в дБ:

```text
A_dB = 20*log10(Vout/Vin)
```

### Пример

| Параметр | Значение |
|---|---:|
| R1 | 9 кОм |
| R2 | 1 кОм |
| Отношение напряжений | 0,1 |
| Ослабление | −20 дБ |

### Практические шаги

1. Выберите требуемое ослабление.
2. Рассчитайте отношение напряжений.
3. Выберите номиналы резисторов.
4. Проверьте влияние импеданса нагрузки.
5. Нарисуйте схему.
6. Измерьте уровни на входе и выходе.
7. Задокументируйте безопасный рабочий диапазон.

### Замечания по безопасности

!!! warning "RF-безопасность"
    Простой делитель напряжения — учебный. Для измерений RF loopback по кабелю, когда важны уровни мощности или согласование импеданса, следует использовать настоящие 50-омные RF-аттенюаторы.
