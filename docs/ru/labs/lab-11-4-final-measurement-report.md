# Лабораторная 11.4 — Итоговый измерительный отчёт

## Цель

Итоговый инженерный отчёт по интегрированному SDR-проекту: QPSK-модем в fabric на Zynq-7020 + AD9361, проверенный на двухплатном RF-канале по кабелю.

## Инженерный вопрос

> Даёт ли проект достаточно доказательств того, что SDR-цепочка работает как задумано?

**Да.** Синтезированный модем PL восстанавливает известный кадр при BER 0 при каждой холодной загрузке через loopback fabric, а на двухплатном RF-канале декодирует непрерывно передаваемый кадр без катастрофических (потеря всего пакета) отказов и с BER payload около 4×10⁻⁴. Доказательства детерминированы, статистичны и воспроизводимы по закоммиченным скриптам.

## Аннотация

Детерминированный пакет QPSK формируется в PL (ROM кадра → дифференциальный кодер → RRC → ЦАП), передаётся платой A по закрытому кабелю SMA + аттенюатор 30 дБ на частоте 915 МГц и принимается платой B, чья RX-цепочка в fabric (DC-блокер → согласованный фильтр → выбор фазы прямой связью → восстановление тайминга по Гарднеру → грубый CFO → восстановление несущей по Костасу → жёсткое решение → дифференциальный декодер → счётчик BER с разрешением квадранта) восстанавливает кадр и оценивает его на кристалле. Канал закрывается при BER 0 в когерентном loopback fabric и при ~4×10⁻⁴ на двух независимых по опоре RF-фронтендах, причём отказы поворота всего пакета устранены дифференциальным кодированием и удлинённой преамбулой.

## Архитектура

```text
Плата A (TX)                          Плата B (RX, модем в fabric)
 ROM кадра (512b)                      AD9361 RX1 ─ АЦП
   │ диф. кодирование (хост)             │
   │ QPSK-маппинг + RRC (SPS=8)          DC-блокер (скользящее среднее, удаление утечки LO)
   │ iio_writedev -c (циклически)        │  согласованный RRC FIR
 AD9361 TX1 ─ ЦАП ── SMA + 30 дБ ──►     │  выбор фазы прямой связью
                     аттенюатор          │  восстановление тайминга по Гарднеру
                                         │  грубый CFO (4-я степень, прямая связь)
                                         │  восстановление несущей по Костасу (gp_ctrl[10])
                                         │  жёсткое решение → диф. декодер (gp_ctrl[17])
                                         │  счётчик BER с разрешением квадранта + телеметрия позиции
                                        gpreg @ 0x79040000 (хост читает счётчики)
```

Runtime-переключатели функций находятся в `gp_ctrl` (DC-блокер, Костас, грубый CFO, выбор фазы, Гарднер, чтение позиции payload, чтение декодированных бит, дифференциальный режим). Плоскость управления/статуса — окно `axi_gpreg` по адресу `0x79040000`.

## Метод

- **Симуляция / RTL:** у каждого блока есть testbench на Icarus; весь набор Блока 5 — 36/36, несколько testbench управляются реальными захватами с платы (`tb_qpsk_rx_costas`, `tb_qpsk_costas_stress`, `tb_qpsk_two_board_residual_cfo`). RTL подкреплён офлайн-моделями, побитово совпадающими с ним (`dc_blocker_margin.py`, `lab_11_43_dqpsk_model.py`).
- **RF:** две платы; плата A — образ вендора Pluto (непрерывная передача `iio_writedev`), плата B — загрузочный образ курса (приём в fabric). Кадр побитово точно пересобирается на Python из того же ROM, что читает RTL.
- **Запись / оценка:** счётчик BER на кристалле оценивает каждый пакет; хост читает счётчики через gpreg (`qpsk_ber_once`). Телеметрия позиции (`gp_ctrl[15]`) и чтение декодированных бит (`gp_ctrl[16]`) локализуют ошибки.

## Результаты

**Loopback fabric (когерентный, детерминированный), кампания холодных загрузок:** 50/50 холодных загрузок декодируют чисто; BPSK+QPSK вместе **5 610 000 бит, 0 ошибок → BER < 5,34×10⁻⁷** (95 %, односторонняя граница, правило трёх).

**Двухплатный RF-канал (A TX1 → 30 дБ → B RX1), 915 МГц:**

| Конфигурация | Чистые кадры | Грубые (поворот всего пакета) | BER payload |
|---|---:|---:|---:|
| абсолютный, lock-tol=1 (140/24) | 98,9 % (1182/1195) | 0,75 % | ~3×10⁻³ |
| **дифференциальный + 24-симв. преамбула (152/48)** | 96,9–98,8 % | **0 %** | **~4×10⁻⁴** |

**Несущая / частота:** собственный межплатный CFO измерен как −194 / −238 / −288 Гц на трёх холодных загрузках; оценщик грубого CFO отслеживает намеренно введённый сдвиг во всём однозначном диапазоне ±60 кГц (Lab 11.31), а петля Костаса убирает остаток, поэтому созвездие неподвижно на протяжении кадра.

## Обсуждение — ограничения и источники ошибок

- **Дифференциальный штраф.** Дифференциальный QPSK стоит присущих ~3 дБ (каждая символьная ошибка даёт две битовые), что видно как остаточная перемежающаяся частота одиночных бит-ошибок, из-за которой число чистых кадров остаётся около 97–99 %, а не 100 %. Это не отказ поворота. Компромисс того стоит: катастрофические пакеты с BER ~46 % исчезли, а суммарный BER упал на порядок.
- **Переходный процесс адаптивной петли.** Дифференциальное декодирование считывает разность фаз между соседними символами, поэтому любая RX-петля, ещё устанавливающаяся в начале payload, портит результат. Исправление (24-символьная преамбула, чтобы payload начинался после захвата) описано в Lab 11.45; более длинная 32-символьная преамбула хуже (доля захвата падает за пределами запаса сэмплера).
- **Зависимость AD9361 от холодного сброса.** Тёплая перезагрузка оставляет BBPLL в таймауте калибровки; после загрузки нового образа PL требуется физическое выключение питания.
- **SNR/EVM отдельно не инструментированы.** Отчётной метрикой сквозного качества служит BER; отдельный захват EVM — возможное будущее дополнение.
