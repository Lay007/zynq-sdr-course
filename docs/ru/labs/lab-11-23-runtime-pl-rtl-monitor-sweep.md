# Лабораторная 11.23 — Сфокусированная развёртка монитора RTL-SDR для runtime/PL вокруг рабочей точки BPSK

## Цель

Выполнить короткую параметрическую развёртку ослабления TX и усиления RX вокруг рабочей точки, подтверждённой в Lab 11.22, используя RTL-SDR как внешний монитор, и записать, как офлайн-BER и EVM меняются с каждой настройкой.

Это превращает однопозиционное измерение Lab 11.22 в небольшую характеризующую таблицу, полезную для выбора лучшей мощности TX и усиления RTL-SDR для надёжного внешнего мониторинга runtime PL BPSK TX в будущих сессиях запуска.

## Конструкция развёртки

Для каждой комбинации `(tx_attenuation_db, rtl_tuner_gain_db10)`:

1. Загрузить overlay `bridge_txrx_mux` (один раз в начале, а не на каждой итерации).
2. Перенастроить ослабление TX AD9361 через сетевой IIO.
3. Выставить `burst_start`.
4. Записать WAV RTL-SDR в течение `--capture-duration-s` секунд.
5. Выполнить офлайн-анализ BER / EVM (код Lab 11.20, вызываемый как библиотека).
6. Собрать `tx_valid_count`, `rx_valid_count`, `received_bits`.
7. Добавить результат в JSON.

Развёртка по умолчанию:

```text
tx_attenuation_db  : -30, -40, -50, -60
rtl_tuner_gain_db10: 100, 200, 300  (= 10, 20, 30 дБ)
```

Всего: 12 точек × ~5 с каждая ≈ ~1 минута.

## Как интерпретировать результат

| Тренд BER | Интерпретация |
|---|---|
| BER = 0 в большинстве точек | OTA-канал устойчив; мощности TX достаточно |
| BER резко растёт при большом ослаблении TX | найден предел бюджета линии |
| BER ненулевой даже при наименьшем ослаблении TX | проблема фильтра RRC или восстановления тайминга |

## Живой результат 2026-06-23

Развёртка подтвердила BER = 0 для значений ослабления TX вплоть до -60 дБ (наименьшее из проверенных) при усилении RTL-SDR ≥ 200 (20 дБ). EVM менялся от 52 % до 60 % по развёртке, что согласуется с однопозиционным результатом Lab 11.22.

Практическая рабочая точка для последующих мониторинговых работ:
- ослабление TX: **-50 дБ**
- усиление тюнера RTL-SDR: **200** (20 дБ)
