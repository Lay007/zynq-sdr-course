# Лабораторная 2.2 — Aliasing sweep

## Цель

Понять, как тоны выше Nyquist складываются обратно в наблюдаемую полосу и почему без модели aliasing нельзя корректно интерпретировать спектр.

## Что выполняется

В работе студент:

1. задаёт реальный sampler с `Fs = 1.0 MHz`;
2. строит alias map для широкого диапазона входных частот;
3. сравнивает спектры для тонов ниже и выше Nyquist;
4. проверяет measured alias frequency против аналитического расчёта.

## Результат

После выполнения работы должны быть получены:

- карта aliasing `input -> observed`;
- примерные спектры для трёх тестовых тонов;
- metrics JSON с expected alias и max alias error;
- вывод о требованиях к anti-alias filtering или выбору `Fs`.

## Что приложить к отчёту

- значение `Fs` и Nyquist frequency;
- график `lab22_aliasing_map.png`;
- график `lab22_aliasing_examples.png`;
- таблицу expected vs measured alias frequencies;
- инженерный вывод о том, как избежать неправильной частотной интерпретации.

## Подробная техническая часть
### Почему это важно

Если тон выше `Fs/2` дискретизируется без адекватной фильтрации, в наблюдаемом спектре оказывается его алиас, а не исходный RF-тон. Без модели наложения измеренный пик можно приписать неверному источнику.

### Эксперимент

Скрипт использует:

- частоту дискретизации `Fs = 1,0 МГц`;
- модель вещественного дискретизатора;
- тестовые тоны на `180 кГц`, `620 кГц` и `1,18 МГц`.

Он строит:

- карту наложения от `0` до `2,5 * Fs`;
- примеры спектров для трёх тестовых тонов;
- измеренные и ожидаемые частоты алиасов.

### Проверки интерпретации

- Тон `180 кГц` должен появиться рядом со своей исходной частотой, потому что он ниже частоты Найквиста.
- Тон `620 кГц` должен сложиться примерно на `380 кГц`.
- Тон `1,18 МГц` должен сложиться примерно на `180 кГц`.
- JSON с метриками должен подтвердить, что измеренные частоты алиасов следуют аналитической модели алиасинга с малой ошибкой.

### Чего ожидать

```text
Input 180000 Hz -> expected alias 180000.000 Hz, measured 179992.676 Hz
Input 620000 Hz -> expected alias 380000.000 Hz, measured 380004.883 Hz
Input 1180000 Hz -> expected alias 180000.000 Hz, measured 179992.676 Hz
```

- Для **вещественного** дискретизатора при `Fs = 1 МГц` наблюдаемая полоса — от 0 до 500 кГц. Тон на частоте `f` появляется на `|f − k*Fs|` при таком целом `k`, что результат попадает в эту полосу.
- **180 кГц и 1,18 МГц дают одинаковый спектр.** По одним отсчётам их не различить. Решить, какой из них пропустить, может только аналоговый фильтр *до* АЦП.
- Разница в несколько герц между ожидаемым и измеренным — квантование по бинам, как в Лабораторной 2.1.

### Упражнения

1. Предскажите алиасы 950 кГц, 1,5 МГц и 2,3 МГц при `Fs = 1 МГц`, затем проверьте.
2. Какие входные частоты от 0 до 3 МГц все попадают ровно на 100 кГц?
3. У приёмника антиалиасинговый фильтр с краем полосы пропускания 450 кГц. Какая полоса входов всё ещё может свернуться в 0–50 кГц, если фильтр достигает подавления 40 дБ только к 950 кГц?
