# Лабораторная 8.1 — Оценка и компенсация частотного рассогласования CFO

## Цель

Понять, почему созвездие QPSK вращается при carrier frequency offset, и научиться оценивать и компенсировать это рассогласование.

## Что выполняется

В работе студент:

1. генерирует QPSK-символы;
2. вносит CFO, phase offset и шум;
3. оценивает CFO методом четвёртой степени;
4. компенсирует CFO и остаточную фазу;
5. сравнивает EVM и BER до/после коррекции.

- constellation plot до коррекции;

### Модель CFO

Сдвиг несущей поворачивает каждый символ на линейно растущую фазу:

```text
r[n] = s[n] * exp(j * (2*pi*f_cfo*n/Fs + phi0)) + noise[n]
```

Если `f_cfo` ненулевой, созвездие не остаётся неподвижным. Оно вращается со временем.

### Метод 4-й степени для QPSK

Для QPSK возведение сигнала в 4-ю степень приблизительно убирает модуляцию данными:

```text
r4[n] = r[n]^4
```

Наклон фазы `r4[n]` в четыре раза больше наклона фазы CFO. Следовательно:

```text
f_cfo_est = slope(angle(r[n]^4)) * Fs / (2*pi*4)
```

Это компактный учебный оценщик. В реальных системах чаще надёжнее оценщики по преамбуле и петли слежения.

### Метрики

| Метрика | Смысл |
|---|---|
| истинный CFO | намеренно введённый частотный сдвиг |
| оценённый CFO | результат оценщика 4-й степени |
| ошибка CFO | оценённый минус истинный CFO |
| EVM до | ошибка созвездия до синхронизации |
| EVM после | ошибка созвездия после коррекции CFO/фазы |
| BER до | BER жёстких решений до коррекции |
| BER после | BER жёстких решений после коррекции |
| остаточная фаза | оценённая постоянная фаза после коррекции CFO |

### Типичные ошибки

| Ошибка | Симптом | Исправление |
|---|---|---|
| неверный знак CFO | вращение ускоряется | изменить знак коррекции |
| фаза не скорректирована | созвездие остаётся повёрнутым | оценить остаточную фазу |
| оценщик применён при малом SNR | оценка CFO зашумлена | использовать более длинное усреднение или преамбулу |
| неверная частота дискретизации | оценка CFO масштабируется неверно | проверить метаданные |
| использование только вещественного сигнала | нарушается симметрия QPSK | использовать комплексный IQ |
