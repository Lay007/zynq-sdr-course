### Модель CFO

Сдвиг несущей поворачивает каждый символ на линейно растущую фазу:

```text
r[n] = s[n] * exp(j * (2*pi*f_cfo*n/Fs + phi0)) + noise[n]
```

Если `f_cfo` ненулевой, созвездие не остаётся неподвижным. Оно вращается со временем.

### Метод 4-й степени для QPSK

Для QPSK возведение сигнала в 4-ю степень приблизительно убирает модуляцию данными:

```text
r4[n] = r[n]^4
```

Наклон фазы `r4[n]` в четыре раза больше наклона фазы CFO. Следовательно:

```text
f_cfo_est = slope(angle(r[n]^4)) * Fs / (2*pi*4)
```

Это компактный учебный оценщик. В реальных системах чаще надёжнее оценщики по преамбуле и петли слежения.

| Метрика | Смысл |

### Типичные ошибки

| Ошибка | Симптом | Исправление |
|---|---|---|
| неверный знак CFO | вращение ускоряется | изменить знак коррекции |
| фаза не скорректирована | созвездие остаётся повёрнутым | оценить остаточную фазу |
| оценщик применён при малом SNR | оценка CFO зашумлена | использовать более длинное усреднение или преамбулу |
| неверная частота дискретизации | оценка CFO масштабируется неверно | проверить метаданные |
| использование только вещественного сигнала | нарушается симметрия QPSK | использовать комплексный IQ |

### Чего ожидать

Запуск по умолчанию (4096 символов QPSK при 1 МС/с, один отсчёт на символ, CFO 2750 Гц, фаза 0,65 рад, шум 0,035 rms, seed 81):

```text
True CFO: 2750.000 Hz
Estimated CFO: 2750.039 Hz
CFO error: 0.039 Hz
EVM before: 141.442 % (3.01 dB)
EVM after: 4.985 % (-26.05 dB)
BER before: 5.002441e-01 (4098/8192)
BER after: 0.000000e+00 (0/8192)
Residual phase estimate: 0.650010 rad
```

- **BER 0,5 до коррекции** означает случайные решения: созвездие поворачивается на `360 * 2750 / 1e6 ≈ 1°` за символ, то есть за 4096 символов делает больше 11 оборотов.
- **Оценка точна до 0,04 Гц**, потому что аппроксимация прямой по 4096 отсчётам очень эффективно усредняет шум при таком SNR.
- **Остаточная фаза 0,650 рад воспроизводит введённые 0,65 рад.** После удаления CFO остаётся одна постоянная фаза. Метрики считаются по собственному выходу приёмника, без предварительного выравнивания по известному эталону, поэтому неверная оценка фазы проявилась бы битовыми ошибками.

!!! note "Важная деталь со знаком"
    Для точек QPSK `(±1±j)/√2` каждый символ в 4-й степени равен `−1`. Поэтому оценка фазы — `angle(−mean(r⁴))/4`. Без знака минус оценка смещена ровно на π/4, и «скорректированное» созвездие ложится на оси I/Q. В этой работе была именно такая ошибка до сентября 2026 года; она была скрыта, потому что BER тогда считался после «идеального» выравнивания по эталону. Та же ловушка на железе описана в [Лабораторной 11.30](lab-11-30-two-board-cfo-validation.md).

### Упражнения

1. Оценщик 4-й степени однозначен при `|CFO| < Fs/8` = 125 кГц. Задайте CFO 50, 100, 110 и 120 кГц. На 100 кГц оценка уже занижена примерно на 175 Гц, а на 120 кГц проваливается примерно до 55 кГц. Почему практический предел ниже 125 кГц? (Подсказка: `np.unwrap` требует, чтобы каждый шаг `angle(r⁴)` от отсчёта к отсчёту оставался меньше π.)
2. Поднимите шум с 0,035 до 0,2 и 0,35. Ошибка оценки растёт до сотен, затем тысяч герц. Объясните, почему оценщик на основе развёртки фазы отказывает резко, а не деградирует плавно.
3. Замените аппроксимацию прямой средним `angle(r⁴[n+1] · conj(r⁴[n]))`. Сравните ошибку при шуме 0,2.
4. Уберите знак минус в `estimate_phase_qpsk` и перезапустите. Укажите EVM и BER после коррекции и объясните их.
