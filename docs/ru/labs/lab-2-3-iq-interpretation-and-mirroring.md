# Лабораторная 2.3 — Интерпретация I/Q и mirrored spectrum

## Цель

Понять разницу между корректной complex I/Q-записью, перестановкой каналов I/Q и real-valued захватом, который даёт зеркальный спектр.

## Что выполняется

В работе студент:

1. формирует комплексный тон в baseband;
2. сравнивает correct complex IQ, swapped I/Q и real-only capture;
3. измеряет peak positions для положительной и отрицательной частей спектра;
4. проверяет, как потеря порядка I/Q или imaginary channel меняет физический смысл спектра.

## Результат

После выполнения работы должны быть получены:

- временной график компонентов I/Q;
- спектральное сравнение correct/swapped/real capture;
- metrics JSON с положением пиков и проверкой зеркальности;
- инженерный вывод о важности правильного порядка I/Q в SDR pipeline.

## Что приложить к отчёту

- график `lab23_iq_components_time.png`;
- график `lab23_iq_interpretation_spectra.png`;
- measured peaks для correct, swapped и mirrored cases;
- краткое объяснение, почему complex baseband различает знак частоты;
- note о том, как ошибка перестановки I/Q проявится в реальной IQ-записи.

## Подробная техническая часть
### Почему это важно

Комплексная основная полоса разделяет положительные и отрицательные частоты. Если порядок I/Q неверен, спектр может оказаться зеркальным. Если используется только вещественный канал, содержимое на положительных и отрицательных частотах становится симметричным, и информация о направлении теряется.

### Эксперимент

Скрипт строит комплексный тон на `120 кГц` и сравнивает три случая:

- корректный комплексный I/Q;
- I/Q, переставленные обменом вещественной и мнимой частей;
- вещественный захват, сохраняющий только канал I.

Работа измеряет:

- положение пика для корректного комплексного сигнала;
- зеркальный пик для случая с переставленными I/Q;
- положительный и отрицательный зеркальные пики для вещественного захвата.

### Проверки интерпретации

- В случае корректного комплексного I/Q главный тон должен быть около `+120 кГц`.
- В случае переставленных I/Q тон должен зеркально отразиться на отрицательную сторону спектра.
- Вещественный захват должен показать одинаковые положительный и отрицательный пики около `+/-120 кГц`.
- JSON с метриками должен подтвердить малую ошибку для корректного случая и почти симметричные зеркальные пики для вещественного.
