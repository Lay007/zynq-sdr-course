# Лабораторная 5.3 — RTL-смеситель IQ на основе NCO

## Цель

Реализовать учебный fixed-point IQ-смеситель на Verilog с фазовым аккумулятором, таблицей sin/cos и комплексным умножением.

## Что выполняется

В работе студент:

1. изучает фазовый аккумулятор NCO;

5. проверяет complex multiply, округление и насыщение.

### Инженерный вопрос

> Как fixed-point цифровой микшер становится тактируемым RTL-блоком с NCO, LUT, комплексным умножителем, округлением и насыщением?

### Уравнение DSP

Для комплексного входа:

```text
x[n] = I[n] + jQ[n]
w[n] = cos(phi[n]) + j sin(phi[n])
y[n] = x[n] * w[n]
```

RTL реализует:

```text
y_i = I*cos - Q*sin
y_q = I*sin + Q*cos
```

### Модель NCO

Учебный RTL использует компактный аккумулятор фазы:

```text
phase[n+1] = phase[n] + phase_increment
```

Для этой работы:

```text
PHASE_W = 4
размер LUT = 16 отсчётов
PHASE_INC = 1
```

Это намеренно мало, чтобы студенты могли изучить все значения LUT и переходы на waveform. Промышленному микшеру SDR нужны более широкий аккумулятор фазы и более качественная реализация генератора.

### Форматы fixed-point

| Сигнал | Формат | Комментарий |
|---|---|---|
| Входные I/Q | Q1.15 | знаковые 16-битные отсчёты |
| LUT sin/cos | Q1.15 | знаковые 16-битные значения генератора |
| Произведение | Q2.30 | результат умножения |
| Аккумулятор | учебный 40-битный аккумулятор | безопасен для суммы/разности |
| Выходные I/Q | Q1.15 | округлены и насыщены |

### Тракт данных RTL

```mermaid
flowchart LR
    PHASE[Аккумулятор фазы] --> LUT[LUT sin/cos]
    LUT --> CMUL[Комплексный умножитель]
    IN[Входные IQ] --> CMUL
    CMUL --> ROUND[Округление до Q1.15]
    ROUND --> SAT[Насыщение]
    SAT --> OUT[Выходные IQ]
```

### Стратегия testbench

Testbench проверяет:

1. поведение при сбросе;
2. выравнивание `out_valid`;
3. продвижение фазы только при valid на входе;
4. знаковое комплексное умножение;
5. округление до Q1.15;
6. границы насыщения;
7. отсчёт-за-отсчётом согласие с эталонными векторами Python.

### Масштабирование к реальным проектам SDR

| Учебная работа | Промышленная версия SDR |

### Чего ожидать

```text
PASS: nco_mixer_iq test completed without errors
```

NCO использует таблицу синуса на 16 значений и `PHASE_INC = 1`, поэтому смеситель поворачивает вход на +22.5 градуса на каждый валидный отсчёт (сдвиг на +fs/16). Эталон на Python использует ту же таблицу, округление и насыщение, поэтому сравнение побитовое.

Раннер курса генерирует векторы, компилирует, запускает симуляцию и считает ошибкой любую строку `FAIL` или ненулевой код выхода симулятора:

```bash
python tools/run_block5_hdl_smoke.py --test tb_nco_mixer_iq
```

На кристалле курса (out-of-context синтез в Vivado 2021.1, `xc7z020clg400-2`, 100 МГц; `python tools/generate_block5_vivado_reports.py`) этот смеситель занимает 110 LUT, 37 FF и 4 DSP48E1 и не укладывается в 100 МГц: WNS -0,807 нс, 16 из 36 конечных точек нарушают ограничение, 15 уровней логики, оценка около 92,6 МГц. Чтение таблицы, комплексное умножение, округление и насыщение выполняются за один такт — тот же шаблон, что у FIR из Lab 5.2 (что с этим шаблоном делает конвейеризация, см. её упражнение 4).

### Упражнения

Каждое упражнение ниже — намеренная мутация RTL в одну строку. Внесите её, запустите testbench, прочитайте сообщения и верните файл (`git checkout -- <file>`). Приведённые выводы получены на Icarus Verilog 12.0.

1. Сделайте смеситель сопряжённым (поворот в другую сторону): `acc_i = I*cos + Q*sin`, `acc_q = -I*sin + Q*cos`. Testbench сообщает 8 ошибок с перевёрнутым знаком Q, например `out=(11087,-4592) expected=(11087,4592)`. Это та же ошибка знака, что в Lab 3.3: сигнал оказывается на -fs/16 вместо +fs/16.
2. Замените округление усечением: `round_q15 = value >>> SHIFT;`. Testbench сообщает 8 ошибок, например `out=(11999,0) expected=(12000,0)`. Обратите внимание: первая возникает на фазе 0, где cos = 32767, а не 32768: 12000 * 32767 / 32768 = 11999.63, что округляется до 12000, но усекается до 11999. Q1.15 не может точно представить +1.0.
3. Оцените динамический диапазон, свободный от паразитных составляющих (SFDR), для таблицы на 16 значений по 16 бит и сравните с правилом «около 6 дБ на бит адреса фазы», измеренным в Lab 3.3. Что бы вы увеличили в первую очередь: длину таблицы или разрядность её слов?
