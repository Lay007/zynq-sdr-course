# Лабораторная 4.1 — FIR-фильтр в fixed-point арифметике

## Цель

Перевести FIR-фильтр из floating-point модели в fixed-point представление и оценить, как квантование коэффициентов и отсчётов влияет на ошибку, спектр и устойчивость реализации.

## Что выполняется

В работе студент:

1. выбирает формат входных данных и коэффициентов;
2. квантует коэффициенты FIR-фильтра;
3. сравнивает floating-point и fixed-point выходы;
4. оценивает ошибку квантования;
5. фиксирует правила округления, насыщения и масштабирования.

## Результат

После выполнения работы должны быть получены:

- таблица fixed-point форматов;
- график ошибки между float и fixed;
- спектры/АЧХ до и после квантования;
- вывод о допустимости выбранного формата для FPGA.

## Что приложить к отчёту

- формат данных, например Q1.15;
- разрядность коэффициентов;
- accumulator width;
- правило rounding/saturation;
- максимальную и RMS-ошибку;
- инженерный вывод для перехода к RTL.

### Инженерный контекст

FIR с плавающей точкой удобен для проектирования алгоритма, но реализация в FPGA требует явных решений о:

- формате входных IQ;
- формате коэффициентов;
- ширине произведения;
- ширине аккумулятора;
- режиме округления;
- режиме насыщения;
- масштабировании выхода;
- допустимой ошибке относительно эталонной модели.

### Цепочка обработки

```mermaid
flowchart LR
    X[Входные IQ, формат Q] --> COEF[Квантованные коэффициенты FIR]
    COEF --> MAC[Fixed-point цепочка MAC]
    X --> MAC
    MAC --> ROUND[Округление / масштабирование]
    ROUND --> SAT[Насыщение]
    SAT --> Y[Выходные IQ]
    Y --> ERR[Ошибка float против fixed]
```

### Рекомендуемые начальные форматы

| Сигнал | Начальный формат | Примечания |
|---|---|---|
| Входные IQ | Q1.15 | нормированные комплексные отсчёты |
| Коэффициенты FIR | Q1.15 | коэффициенты Блэкмана/оконного sinc |
| Произведение | Q2.30 | умножение Q1.15 на Q1.15 |
| Аккумулятор | Q6.30 или шире | зависит от числа коэффициентов |
| Выходные IQ | Q1.15 | после округления и насыщения |

Для FIR с `N` коэффициентами используйте не менее:

```text
guard_bits = ceil(log2(N))
```

дополнительных бит аккумулятора.

### Эталонные реализации

Исполняемые скрипты на Python и MATLAB реализуют один и тот же эксперимент:

1. генерируют комплексный IQ-сигнал с полезным тоном, помехой и шумом;
2. проектируют низкочастотный FIR с окном Блэкмана;
3. квантуют входные отсчёты и коэффициенты в Q1.15;
4. запускают учебную целочисленную fixed-point модель FIR;
5. сравнивают выходы с плавающей и фиксированной точкой;
6. считают RMS-ошибку, максимальную ошибку, SQNR, защитные биты и число насыщений;
7. сохраняют графики сравнения.

### Обязательные графики

Постройте как минимум:

1. АЧХ FIR с плавающей точкой;
2. АЧХ FIR с квантованными коэффициентами;
3. спектр до фильтрации;
4. спектр после float FIR;
5. спектр после fixed FIR;
6. спектр ошибки или ошибку во временной области.

### Метрики

| Метрика | Как считать | Инженерный смысл |
|---|---|---|
| RMS-ошибка | `rms(y_float - y_fixed)` | средняя ошибка реализации |
| SQNR | RMS сигнала / RMS ошибки | качество квантования |
| Максимальная абсолютная ошибка | `max(abs(error))` | наихудшее отклонение |
| Дельта полосы заграждения | полоса заграждения float против квантованной | влияние квантования коэффициентов |
| Число насыщений | число обрезанных выходных отсчётов | качество масштабирования |

### Отображение на HDL

Fixed-point FIR отображается на потоковый блок:

```text
input  wire              clk
input  wire              rst
input  wire              in_valid
input  wire signed [15:0] in_i
input  wire signed [15:0] in_q
output wire              out_valid
output wire signed [15:0] out_i
output wire signed [15:0] out_q
```

Варианты реализации:

| Архитектура | Плюсы | Минусы |
|---|---|---|
| Полностью параллельный FIR | максимальная пропускная способность | много умножителей |
| MAC, мультиплексированный по времени | меньше ресурсов | ниже пропускная способность / больше управляющей логики |
| Симметричный FIR | меньше умножителей | только для симметричных коэффициентов |
