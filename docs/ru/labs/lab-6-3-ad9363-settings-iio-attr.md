# Лабораторная 6.3 — Настройки AD9363 и iio_attr

## Цель

Научиться фиксировать параметры AD9363 через IIO/iio_attr так, чтобы RF-эксперимент можно было воспроизвести позднее.

## Что выполняется

В работе студент:

1. находит доступные IIO-устройства;
2. просматривает атрибуты PHY и каналов;
3. задаёт LO frequency, sample rate и RF bandwidth;
4. фиксирует gain mode и hardware gain;
5. оформляет настройки в metadata/checklist.

## Результат

После выполнения работы должны быть получены:

- список используемых IIO-устройств;
- набор команд `iio_attr`;
- таблица настроек AD9363;
- пример metadata для RF-захвата;
- вывод о воспроизводимости эксперимента.

## Что приложить к отчёту

- вывод discovery-команд;
- частоты LO;
- sample rate и RF bandwidth;
- gain settings;
- ссылку на metadata JSON;
- инженерный вывод.

## Подробная техническая часть

### Инженерный контекст

В реальном SDR-эксперименте наблюдаемый сигнал зависит не только от DSP-кода. Он зависит и от настроек RF-фронтенда:

- частота LO;
- RF-полоса;
- частота дискретизации;
- режим усиления;
- аппаратное усиление;
- включённые каналы;
- состояние аналоговых фильтров;
- внешнее ослабление;
- поведение AGC/ручного усиления.

Если этих настроек нет, IQ-запись невоспроизводима.

### Типичные имена IIO-устройств

Точные имена зависят от образа платы и конфигурации Linux/IIO. Часто встречаются:

```text
ad9361-phy
cf-ad9361-lpc
cf-ad9361-dds-core-lpc
```

Некоторые платы показывают трансивер AD9363 под IIO-именем, совместимым с `ad9361-phy`. Всегда проверяйте, какие устройства доступны в вашей системе.

### Команды обнаружения

Список IIO-устройств:

```bash
iio_info -s
```

Атрибуты устройства:

```bash
iio_attr -d ad9361-phy
```

Атрибуты каналов:

```bash
iio_attr -c ad9361-phy
```

Один канал:

```bash
iio_attr -c ad9361-phy voltage0
```

### Python-проба на стороне хоста

Для воспроизводимой проверки на стороне хоста в репозитории есть:

```bash
python blocks/block_06_rf_frontend_and_ad9363/python/lab_6_3_probe_iio_context.py \
  --uri ip:192.168.40.1 \
  --json-out docs/assets/lab63_zynq_iio_probe.json
```

Скрипт открывает удалённый контекст IIO, перечисляет устройства и каналы и печатает компактную сводку AD9361 с RX/TX LO, полосой, частотой дискретизации и настройками усиления. В Windows он также пробует стандартный путь установки `IIO Oscilloscope` для `libiio.dll`.

### Типичные параметры RX

| Назначение | Пример команды | Примечания |
|---|---|---|
| Частота LO RX | `iio_attr -c ad9361-phy altvoltage0 frequency 915000000` | имя канала может отличаться |
| RF-полоса RX | `iio_attr -c ad9361-phy voltage0 rf_bandwidth 2000000` | Гц |
| Частота дискретизации RX | `iio_attr -c ad9361-phy voltage0 sampling_frequency 2400000` | Гц |
| Режим управления усилением RX | `iio_attr -c ad9361-phy voltage0 gain_control_mode manual` | для измерений предпочтителен manual |
| Аппаратное усиление RX | `iio_attr -c ad9361-phy voltage0 hardwaregain 10` | дБ, диапазон зависит от железа |

### Типичные параметры TX

| Назначение | Пример команды | Примечания |
|---|---|---|
| Частота LO TX | `iio_attr -c ad9361-phy altvoltage1 frequency 915000000` | имя канала может отличаться |
| RF-полоса TX | `iio_attr -c ad9361-phy voltage0 rf_bandwidth 2000000` | имена выходных каналов могут отличаться |
| Частота дискретизации TX | `iio_attr -c ad9361-phy voltage0 sampling_frequency 2400000` | проверьте устройство/канал TX |
| Ослабление / усиление TX | `iio_attr -c ad9361-phy voltage0 hardwaregain -20` | знак/диапазон зависят от платы |

!!! note "Имена, зависящие от платы"
    Точные имена каналов для LO RX/TX и каналов voltage могут отличаться. Воспринимайте команды выше как шаблон чек-листа, а не как гарантированно универсальный набор команд.

### Безопасная процедура настройки

1. Подключите аттенюатор до включения TX.
2. Используйте низкий уровень TX / большое ослабление TX.
3. Используйте ручное усиление RX для воспроизводимости.
4. Задайте частоты LO.
5. Задайте частоты дискретизации.
6. Задайте RF-полосы.
7. Сформируйте одиночный тон низкого уровня.
8. Посмотрите на спектр в поисках перегрузки.
9. Сохраните настройки и IQ-метаданные.
10. Только после этого переходите к экспериментам с модуляцией.

### Пример журнала сессии

```bash
# Обнаружить устройства
iio_info -s

# Осмотреть PHY
iio_attr -d ad9361-phy

# Примеры центральных частот
iio_attr -c ad9361-phy altvoltage0 frequency 915000000
iio_attr -c ad9361-phy altvoltage1 frequency 915000000

# Примеры полосы и частоты дискретизации
iio_attr -c ad9361-phy voltage0 rf_bandwidth 2000000
iio_attr -c ad9361-phy voltage0 sampling_frequency 2400000

# Пример ручного усиления
iio_attr -c ad9361-phy voltage0 gain_control_mode manual
iio_attr -c ad9361-phy voltage0 hardwaregain 10
```
