# Лабораторная 8.8 — QPSK-модем, искажения и BER

## Цель

Расширить BPSK-тракт до QPSK с двумя битами на символ и проверить два уровня реализации:

1. синтезируемый QPSK-модем, восстанавливающий полный кадр с `BER = 0` в идеальном HDL-loopback;
2. модель канала с AWGN и CFO, показывающую влияние искажений на созвездие и BER.

## Модем и проверка

QPSK использует две ортогональные BPSK-оси. Mapper формирует Gray-кодированные точки, после чего общий тракт выполняет upsampling, RRC-фильтрацию, выборку символов и hard decision:

```text
dibit source → QPSK mapper → upsampler → RRC TX → loopback →
RRC RX → symbol sampler → hard decision → BER counter
```

Testbench `tb_qpsk_zynq_ber_top` проверяет 140 символов / 280 бит и получает `BER = 0`.

## Искажения

- AWGN размывает четыре кластера и при снижении `Eb/N0` вызывает пересечение границ решений.
- CFO поворачивает созвездие от символа к символу и без коррекции превращает четыре точки в кольцо.
- Для Gray QPSK теоретическая побитовая вероятность ошибки совпадает с BPSK: `Q(√(2·Eb/N0))`.
