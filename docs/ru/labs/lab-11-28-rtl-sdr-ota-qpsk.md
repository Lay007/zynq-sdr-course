# Лабораторная 11.28 — Runtime QPSK через внешний RTL-SDR

## Цель

Передать детерминированный кадр QPSK из PL двойного модема через AD9361/TX1, записать его независимым RTL-SDR и измерить BER, EVM, остаточный сдвиг частоты и ограничение относительно точного содержимого RTL ROM.

## Команды

Используйте маломощный антенный тракт или рассчитанный ослабленный кабельный тракт. Измеренный антенный прогон использовал:

```powershell
python blocks/block_11_integrated_sdr_project/python/lab_11_22_capture_runtime_pl_rtl_monitor_wav.py `
  --modulation qpsk `
  --bit-bin-path tmp/bridge_txrx_mux.qpsk.cdcfix_20260707.wordswap.bit.bin `
  --center-frequency-hz 868300000 `
  --tx-attenuation-db -50 `
  --rtl-tuner-gain-db10 300 `
  --start-offset 62 `
  --qpsk-symbol-count 140 `
  --runtime-repeat-count 30 `
  --runtime-repeat-gap-ms 40 `
  --rebind-runtime-dds-driver `
  --rebind-runtime-adc-driver `
  --runtime-dds-ratecntrl 3
```

Проанализируйте созданный манифест:

```powershell
python blocks/block_11_integrated_sdr_project/python/lab_11_28_read_rtl_wav_ota_qpsk.py `
  --manifest datasets/lab11_22_runtime_pl_rtl_monitor/manifest_live_20260707_qpsk_ota_cdcfix_02.yaml
```

## Расчёт метрик

Анализатор использует точный QPSK RTL ROM в качестве эталона. Он убирает одну глобальную оценку DC, обнаруживает энергию пакета по порогу медиана/MAD, применяет согласованный фильтр RRC и требует нормированную корреляцию с эталоном `>= 0,8`. Затем он оценивает CFO по линейному наклону фазы `rx * conj(reference)`, убирает один комплексный коэффициент усиления/фазы и принимает решения по знакам I/Q.

Точные формулы BER, FER, EVM, SNR по EVM, CFO, ограничения и доверительных интервалов определены в `docs/digital-link-metrics.md`. В частности, `snr_from_evm_db = -20 log10(EVM_RMS)` — диагностическая оценка при доминировании шума, а не калиброванный RF SNR.
