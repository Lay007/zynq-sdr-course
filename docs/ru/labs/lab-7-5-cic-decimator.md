# Lab 7.5 — CIC-дециматор для SDR-приёмника

Эта лабораторная усиливает мост DSP → fixed-point → FPGA. Это не notebook-упражнение, а детерминированная script-driven лабораторная работа, которая генерирует графики и machine-readable метрики для CI.

## Цель

Смоделировать CIC-дециматор как аппаратно-ориентированный multirate-блок и измерить:

- АЧХ CIC-фильтра;
- поведение при децимации;
- aliasing мешающего тона после изменения частоты дискретизации;
- passband droop;
- рост разрядности аккумуляторов;
- fixed-point последствия для RTL-реализации.

## Почему CIC важен

CIC-дециматор полезен в SDR-приёмниках, потому что может снижать высокую входную частоту дискретизации при помощи сумматоров, вычитателей и задержек без умножителей. Это делает его естественным мостом от теории DSP к FPGA-реализации.

Типичное место в тракте приёмника:

```text
RF frontend / ADC stream -> CIC decimator -> compensation FIR -> channel filter -> demodulator
```

## Чего ожидать

CIC по умолчанию: `R = 8`, `N = 4` каскада, `M = 1`, 16-битный вход, 9,6 МС/с на входе, 1,2 МС/с на выходе; полезный тон 220 кГц, блокирующая помеха 1,85 МГц.

```text
CIC decimation: 9600000 -> 1200000 Hz
Recommended accumulator width: 28 bits
Wanted-tone droop: -1.913 dB
Measured output peak: 219982.910 Hz
```

- **Рост разрядности — `N * log2(R * M) = 4 * 3 = 12` бит**, поэтому 16-битному входу нужны 28-битные интеграторы. Интеграторам разрешено переполняться: в дополнительном коде и при достаточной ширине гребенчатые звенья точно компенсируют переполнение.
- **Спад −1,913 дБ на 220 кГц** следует из `|sin(pi*f*R/fs)/(R*sin(pi*f/fs))|^N`. Этот наклон полосы пропускания у края выходной полосы исправляет компенсирующий FIR после CIC.
- **Помеха 1,85 МГц накладывается на −550 кГц** на выходе (1,85 − 2 × 1,2 МГц), ослабленная характеристикой CIC примерно на 53 дБ. Нули CIC лежат только на кратных выходной частоты; между ними подавление умеренное.
