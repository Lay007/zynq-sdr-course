# Лабораторная 2.1 — Частотная ось дискретизации и интерпретация

## Цель

Понять, как одна и та же запись может выглядеть правдоподобно на FFT-графике, но приводить к неверному выводу, если неправильно интерпретировать `Fs`.

## Что выполняется

В работе студент:

1. строит временной preview комплексного сигнала;
2. рассчитывает FFT с корректной и намеренно неправильной частотной осью;
3. сравнивает measured peak для правильного и ошибочного `Fs`;
4. фиксирует frequency error и проверяет влияние DC offset и шума.

## Результат

После выполнения работы должны быть получены:

- график временной формы I/Q;
- сравнение корректной и ошибочной FFT-оси;
- metrics JSON с expected tone и двумя вариантами интерпретации;
- инженерный вывод о критичности metadata `Fs`.

## Что приложить к отчёту

- значение `Fs`, длину FFT и expected tone;
- график `lab21_sampling_time_domain.png`;
- график `lab21_sampling_frequency_axis.png`;
- measured peak для correct/wrong interpretation;
- краткий вывод о том, почему визуально похожий спектр не гарантирует правильный инженерный смысл.

## Подробная техническая часть
### Почему это важно

Спектр имеет смысл только вместе с правильным `Fs`. Если `Fs` указан неверно, каждый бин FFT отображается на неверную физическую частоту, даже когда форма графика по-прежнему выглядит правдоподобно.

### Эксперимент

Скрипт генерирует комплексный тон со следующими параметрами:

- корректная частота дискретизации `Fs = 1,0 МГц`;
- намеренно неверная интерпретация `Fs = 0,8 МГц`;
- ненулевое смещение DC;
- аддитивный шум;
- известный ожидаемый тон около `123,456 кГц`.

Работа сравнивает:

- временной предпросмотр I/Q;
- модуль FFT с корректной частотной осью;
- тот же модуль FFT с неверной частотной осью;
- измеренную ошибку частоты пика для обеих интерпретаций.

### Запуск

Из корня репозитория:

```bash
python blocks/block_02_signals_and_sampling/python/sampling_analysis.py
```

Или запустите представительный набор лабораторных:

```bash
python tools/run_all_labs.py
```

### Проверки интерпретации

- Верная интерпретация должна помещать тон рядом с ожидаемыми `123,456 кГц`.
- Неверная интерпретация должна заметно сдвигать измеренный пик, хотя форма спектра по-прежнему выглядит разумной.
- JSON с метриками должен показывать малую ошибку для верной оси и намного большую для неверной.
- Временной предпросмотр также помогает выявить смещение DC и риск ограничения до перехода к выводам в частотной области.
