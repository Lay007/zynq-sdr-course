# Лабораторная 5.2 — Отображение FIR-фильтра в RTL

## Цель

Понять, как fixed-point FIR-фильтр из модели переносится в синтезируемую RTL-архитектуру с регистрами задержки, умножителями, аккумулятором, округлением и насыщением.

## Что выполняется

В работе студент:

1. изучает 4-tap IQ FIR на Verilog;
2. генерирует эталонные векторы Python-скриптом;
3. запускает self-checking testbench;
4. проверяет совпадение RTL с fixed-point эталоном;
5. анализирует задержку, разрядность и насыщение.

## Результат

После выполнения работы должны быть получены:

- RTL-модуль FIR-фильтра;
- входные и ожидаемые test vectors;
- VCD waveform;
- PASS/FAIL лог симуляции;
- таблица разрядностей datapath.

## Что приложить к отчёту

- структуру FIR datapath;
- коэффициенты фильтра;
- product width и accumulator width;
- правило округления и насыщения;
- результат симуляции;
- вывод о готовности блока к Vivado/FPGA flow.

### Инженерный вопрос

> Как модель FIR в Q1.15 становится тактируемым RTL-трактом данных с явными умножителями, ростом разрядности аккумулятора, округлением и насыщением?

### Входные данные из Блока 4

| Параметр | Пример | Следствие для RTL |
|---|---:|---|
| Формат входа | Q1.15 | знаковые 16-битные входные порты |
| Формат коэффициентов | Q1.15 | знаковое 16-битное ROM коэффициентов |
| Число коэффициентов | 4 в исполняемой работе, 129 в полном проекте | длина сдвигового регистра и число умножителей |
| Формат произведения | Q2.30 | 32-битные произведения |
| Защитные биты | ceil(log2(N)) | аккумулятор должен быть шире произведения |
| Формат выхода | Q1.15 | округление/насыщение перед выходом |

### Тракт данных FIR

```mermaid
flowchart LR
    IN[Входной отсчёт] --> SR[Сдвиговый регистр]
    SR --> MUL[Умножители на коэффициенты]
    COEF[ROM коэффициентов] --> MUL
    MUL --> SUM[Сумматорное дерево / аккумулятор]
    SUM --> ROUND[Округление до Q1.15]
    ROUND --> SAT[Насыщение]
    SAT --> OUT[Выходной отсчёт]
```

### Уравнение FIR в прямой форме

```text
y[n] = sum_{k=0}^{N-1} h[k] * x[n-k]
```

Для комплексного IQ один и тот же FIR с вещественными коэффициентами применяется независимо к I и Q:

```text
y_i[n] = sum h[k] * x_i[n-k]
y_q[n] = sum h[k] * x_q[n-k]
```

### Исполняемый пример на 4 коэффициента

Исполняемая работа использует такой набор коэффициентов Q1.15:

```text
h = [0.125, 0.375, 0.375, 0.125]
h_q15 = [4096, 12288, 12288, 4096]
```

Он намеренно достаточно мал, чтобы разобраться в нём в просмотрщике waveform, но при этом демонстрирует полный шаблон fixed-point FIR:

- сдвиговый регистр;
- умножение на коэффициенты;
- рост разрядности аккумулятора;
- округление обратно до Q1.15;
- насыщение;
- выравнивание сигнала valid на выходе;
- сравнение с эталонными векторами.

### Варианты архитектуры

| Архитектура | Использование DSP | Пропускная способность | Задержка | Когда применять |
|---|---:|---:|---:|---|
| Полностью параллельная | высокое | один отсчёт за такт | малая/средняя | потоковая обработка на высокой скорости |
| Мультиплексированный по времени MAC | низкое | один отсчёт за много тактов | высокая | низкая скорость или ограниченные ресурсы |
| Симметричный FIR | среднее | один отсчёт за такт | средняя | линейная фаза, симметричные коэффициенты |
| Полифазный FIR | среднее/высокое | эффективное изменение частоты | средняя | дециматор/интерполятор |

### Размер аккумулятора

Для знакового входа Q1.15 и коэффициентов Q1.15:

```text
ширина произведения = 16 + 16 = 32 бита
дробных бит произведения = 15 + 15 = 30 бит
защитные биты = ceil(log2(Ntaps))
ширина аккумулятора >= 32 + guard_bits
```

Для исполняемой 4-коэффициентной работы:

```text
guard_bits = 2
ширина аккумулятора >= 34 бита
```

Для практического FIR на 129 коэффициентов:

```text
guard_bits = 8
ширина аккумулятора >= 40 бит
```

### Каркас RTL

```verilog
module fir_iq_stream #(
    parameter integer W = 16,
    parameter integer NTAPS = 129,
    parameter integer ACC_W = 40
)(
    input  wire                 clk,
    input  wire                 rst,
    input  wire                 in_valid,
    input  wire signed [W-1:0]  in_i,
    input  wire signed [W-1:0]  in_q,
    output reg                  out_valid,
    output reg  signed [W-1:0]  out_i,
    output reg  signed [W-1:0]  out_q
);

// Учебный каркас: настоящее ROM коэффициентов, сдвиговый регистр,
// массив умножителей, сумматорное дерево, округление и насыщение
// добавляются шаг за шагом в лабораторных по реализации.

endmodule
```

### Стратегия testbench

Используйте эталонные векторы из Python/MATLAB Lab 4.1 или из локального генератора векторов FIR.

Рекомендуемые тесты:

1. единичный импульс на входе -> выход совпадает с последовательностью коэффициентов;
2. постоянный вход -> выход приближается к коэффициенту усиления по постоянному току;
3. двухтональный вход -> подавление помехи совпадает с эталоном;
4. случайный вектор IQ -> отсчёт-за-отсчётом сравнение после компенсации задержки;
5. вектор стресса насыщения -> выход детерминированно ограничивается.

### Документирование задержки

Задержку необходимо указывать явно:

| Этап | Задержка, такты |
|---|---:|
| Входной регистр | 1 |
| Обновление сдвигового регистра | 0/1 |
| Конвейер умножителя | 1–3 |
| Сумматорное дерево | зависит от глубины дерева |
| Округление/насыщение | 1 |
| Выходной регистр | 1 |
