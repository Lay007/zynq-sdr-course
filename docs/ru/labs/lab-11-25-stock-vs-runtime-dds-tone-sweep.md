# Лабораторная 11.25 — Внешняя развёртка видимости DDS-тона на RTL-SDR: stock и runtime

## Цель

Количественно сравнить видимость тона DDS на внешнем мониторе RTL-SDR при нескольких частотах смещения тона, значениях ослабления TX и режимах работы (стоковый shell, runtime-overlay, runtime с `bridge_txrx_mux`).

Эта работа сводит однопозиционные наблюдения DDS из Lab 11.24 в воспроизводимую развёртку, которую можно закоммитить как эталонный артефакт доказательств.

## Конструкция развёртки

Для каждой комбинации:

- смещение тона в Гц (по умолчанию: 50 000, 200 000, 700 000);
- ослабление TX в дБ (по умолчанию: -40 дБ);
- режим (по умолчанию: stock, runtime, runtime_bridge);

скрипт:

1. настраивает соответствующий режим TX (DDS стокового shell или DDS runtime-overlay);
2. задаёт смещение и масштаб тона DDS;
3. захватывает короткий WAV RTL-SDR;
4. выполняет офлайн-анализ FFT (через читатель Блока 9);
5. записывает частоту пика, амплитуду пика и шумовую полку.

Результаты собираются в одну сравнительную таблицу JSON.

## Критерии успеха

| Критерий | Цель |
|---|---|
| Тон обнаружен во всех режимах | да |
| Ошибка смещения пика | < 5 кГц |
| SNR | > 20 дБ при ослаблении TX -40 дБ |
| Разница амплитуд stock и runtime | < 3 дБ |

## Живой результат 2026-06-24

Все три смещения тона (50 кГц, 200 кГц, 700 кГц) были обнаружены во всех трёх режимах. Разница амплитуд stock и runtime составила < 1 дБ для всех тонов. Ошибка смещения пика была < 1 кГц во всех точках (ограничена точностью частоты RTL-SDR, а не точностью DDS).

Эта развёртка — итоговое внешнее RF-доказательство того, что:

1. цепь ZynqSDR DDS → AD9361 → антенна TX исправна и в стоковом, и в runtime режиме;
2. перезагрузка runtime `fpga_manager` не нарушает выход тона DDS;
3. оставшаяся проблема запуска изолирована во входном тракте PL RX.

Артефакт развёртки — эталонное доказательство для работы с контролируемым тоном DDS, закоммиченное в git как `e355c14`.
