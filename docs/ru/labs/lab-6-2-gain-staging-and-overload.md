# Лабораторная 6.2 — Настройка усиления и контроль перегрузки

## Цель

Научиться выбирать безопасные уровни TX/RX, обнаруживать перегрузку RF/ADC-тракта и документировать gain settings для воспроизводимых экспериментов.

## Что выполняется

В работе студент:

1. задаёт безопасную схему подключения с аттенюатором;
2. выбирает ручной режим усиления;
3. выполняет gain sweep;
4. фиксирует признаки нормального режима и перегрузки;
5. оценивает SNR, SFDR и запас до клиппинга.

## Результат

После выполнения работы должны быть получены:

- таблица настроек gain/attenuation;
- спектр в нормальном режиме;
- пример или описание перегрузки;
- рекомендуемые безопасные настройки;
- вывод о пригодности уровня сигнала для измерений.

## Что приложить к отчёту

- схему RF level chain;
- TX/RX gain;
- внешнее ослабление;
- peak level и noise floor;
- признаки перегрузки или их отсутствие;
- инженерный вывод.

### Цепочка RF-уровней

```mermaid

```

### Безопасная отправная точка

Для первого кабельного эксперимента используйте консервативные настройки:

| Параметр | Рекомендуемый старт | Комментарий |
|---|---:|---|
| Усиление TX | минимум или сильно уменьшено | избежать повреждения/перегрузки приёмника |
| Внешнее ослабление | 30–60 дБ | обязательно для прямых кабельных тестов |
| Усиление RX | низкое/ручное | отключите AGC для воспроизводимости |
| Тип сигнала | одиночный тон | самый простой индикатор перегрузки |
| Смещение тона | 50–200 кГц | подальше от DC и края полосы |
| Диапазон наблюдения | внутри полосы RX | избегать краевых эффектов |

!!! warning "Не пропускайте ослабление"
    Прямой кабель TX–RX без ослабления может перегрузить или повредить чувствительный приёмник. Начинайте с большим ослаблением, чем кажется необходимым.

### Нормальный и перегруженный спектр

| Наблюдение | Нормальный режим | Режим перегрузки |
|---|---|---|
| Главный тон | узкий устойчивый пик | искажённая или плоская область |
| Гармоники | отсутствуют или малы | сильные гармоники/побочные составляющие |
| Шумовая полка | стабильна | растёт с уровнем сигнала |
| Реакция на усиление | предсказуема | сжата или не меняется |
| Форма во времени | близка к синусоиде | обрезана / «квадратная» |

### Процедура развёртки усиления

1. Настройте фиксированный частотный план из Lab 6.1.
2. Задайте внешнее ослабление.
3. Отключите AGC, если возможно.
4. Начните с малого усиления TX и малого усиления RX.
5. Запишите уровень главного пика и шумовую полку.
6. Увеличивайте усиление RX небольшими шагами.
7. Остановитесь, когда появятся признаки перегрузки.
8. Вернитесь к последней чистой настройке.
9. При необходимости повторите для усиления TX.

### Простые метрики перегрузки

#### Оценка запаса по амплитуде

```text
headroom = clipping_level - peak_level
```

#### Оценка динамического диапазона, свободного от побочных составляющих

```text
SFDR = main_peak_level - largest_spur_level
```

#### Оценка отношения сигнал/шум

```text
SNR = main_peak_level - noise_floor_level
```

Эти оценки — приближения по дисплею спектра. Для строгой работы определите полосу, окно, усреднение и метод калибровки.

### Проверка без железа (синтетическая)

`lab_6_2_gain_overload_sweep.py` превращает записи в таблицу измерений выше. До появления платы запустите его самотест. Он использует **синтетические** записи (тон, амплитуда которого следует смоделированному усилению, плюс фиксированный шум, ограниченные на +/-1,0 по I и Q), каждая строка помечена `[SYNTHETIC]`, и ничто из этого не является аппаратным измерением:

```bash
python blocks/block_06_rf_frontend_and_ad9363/python/lab_6_2_gain_overload_sweep.py --self-test --output lab62_selftest.json --markdown-output lab62_selftest.md
```

| Усиление (сим.) | Наблюдаемый пик | SNR (пик / медианный бин) | SFDR (пик / наибольший другой бин) | Флаг |
|---:|---:|---:|---:|---|
| -20 дБ | -26.56 dBFS | 25.1 дБ | 13.1 дБ | none |
| -10 дБ | -27.29 dBFS | 35.5 дБ | 23.6 дБ | none |
| 0 дБ | -23.67 dBFS | 45.6 дБ | 34.7 дБ | none |
| 20 дБ | -9.50 dBFS | 65.6 дБ | 54.8 дБ | none |
| 30 дБ | -0.15 dBFS | 75.4 дБ | 64.1 дБ | marginal |
| 34 дБ | +2.75 dBFS | 79.6 дБ | 19.1 дБ | clipping |

Чему учат синтетические строки ещё до реальной записи:

- **При -20 и -10 дБ «наблюдаемый пик» — это шум, а не тон.** Амплитуда тона 0,003 и 0,0095, а наибольший отсчёт шума на 8192 точках около 0,047 (пик -26,56 dBFS). Пик даже не растёт между этими строками.
- **SNR по медиане продолжает расти и при клиппинге** (75,4 дБ при 30 дБ, 79,6 дБ при 34 дБ). Клиппинг переносит мощность в несколько гармонических бинов, и медиана всех бинов почти не меняется. **SFDR обваливается с 64,1 до 19,1 дБ** — это и есть признак перегрузки в спектре.
- **+2,75 dBFS возможно**, потому что пик — это модуль комплексного отсчёта, а полная шкала задана отдельно для I и Q. У тона, ограниченного по обеим шинам, угол равен sqrt(2), около +3 dBFS.
- Строка 30 дБ ещё не клиппирует, но её пик ближе 1 дБ к полной шкале, поэтому она помечена `marginal` и не рекомендуется.

В этой модели шум добавляется после усиления, как шум АЦП, поэтому SNR растёт дБ в дБ с усилением. В реальном приёмнике шум входного каскада усиливается вместе с сигналом, поэтому SNR перестаёт улучшаться, как только этот шум начинает доминировать. Найти этот излом — задача аппаратной развёртки.

### Упражнения

1. Объясните по таблице, почему развёртка усиления, оцениваемая только по медианному SNR, выбрала бы точку с клиппингом как лучшую.
2. В `synthetic_capture()` сделайте так, чтобы шум масштабировался тем же усилением, что и тон (модель шума входного каскада). Предскажите столбцы SNR и SFDR, затем запустите.

### Типичные ошибки

| Ошибка | Результат | Исправление |
|---|---|---|
| AGC включён во время измерения | усиление меняется в ходе эксперимента | использовать ручное усиление |
| нет внешнего ослабления | риск перегрузки или повреждения | добавить аттенюатор |
| тон слишком близко к DC | побочный пик DC скрывает сигнал | сместить тон от DC |
| тон у края полосы | спад фильтра меняет уровень | сместить тон к центру |
| только скриншот без настроек | эксперимент нельзя воспроизвести | записать метаданные |
