# Лабораторная 5.8 — Согласованный фильтр BPSK RX и восстановление бит

## Цель

Превратить детерминированный синтетический захват Блока 11 в воспроизводимую приёмную RTL-цепочку:

```text
скорректированный захват -> согласованный RRC-фильтр -> символьный тайминг с фиксированной фазой -> жёсткое решение -> восстановленные биты
```

Это первый исполняемый якорь RX в HDL-маршруте, ориентированный на BER.

## Исполняемый HDL-пакет

| Файл | Назначение |
|---|---|
| `blocks/block_05_fpga_hdl_flow/rtl/bpsk_rrc_rx_fir.v` | обёртка RX вокруг общего 65-коэффициентного RRC FIR |
| `blocks/block_05_fpga_hdl_flow/rtl/bpsk_symbol_timing_sampler.v` | выбирает один символьный отсчёт каждые `8` отсчётов после известного начального смещения |
| `blocks/block_05_fpga_hdl_flow/rtl/bpsk_hard_decision.v` | отображает знак выбранного символа в бит `0/1` |
| `blocks/block_05_fpga_hdl_flow/python/generate_bpsk_rx_bit_recovery_vectors.py` | генерирует векторы скорректированного захвата и ожидаемые восстановленные биты |
| `blocks/block_05_fpga_hdl_flow/tb/tb_bpsk_rx_bit_recovery.v` | самопроверяющийся testbench восстановления RX |

Запуск из корня репозитория:

```bash
python blocks/block_05_fpga_hdl_flow/python/generate_bpsk_rx_bit_recovery_vectors.py

iverilog -g2012 \
  -o blocks/block_05_fpga_hdl_flow/tb/tb_bpsk_rx_bit_recovery.out \
  blocks/block_05_fpga_hdl_flow/rtl/bpsk_rrc_tx_fir.v \
  blocks/block_05_fpga_hdl_flow/rtl/bpsk_rrc_rx_fir.v \
  blocks/block_05_fpga_hdl_flow/rtl/bpsk_symbol_timing_sampler.v \
  blocks/block_05_fpga_hdl_flow/rtl/bpsk_hard_decision.v \
  blocks/block_05_fpga_hdl_flow/tb/tb_bpsk_rx_bit_recovery.v

vvp blocks/block_05_fpga_hdl_flow/tb/tb_bpsk_rx_bit_recovery.out
```

Ожидаемый результат:

```text

```

## Тракт данных

```mermaid
flowchart LR
    CAP[Скорректированный захват Q1.15] --> MF[Согласованный фильтр RRC]
    MF --> TS[Выборка символов с известной фазой]
    TS --> HD[Жёсткое решение]
    HD --> BITS[Восстановленные биты]
    BITS --> CMP[Сравнение с tx_bits.txt]
```

## Почему этот этап важен

Передающей цепочки недостаточно, когда курс переходит к BER. Маршруту модема, ориентированному на BER, нужны:

1. детерминированная согласованная фильтрация;
2. воспроизводимый выбор символов;
3. явные решения по битам;
4. побитовое сравнение с известным исходным кадром.

Эта работа даёт все четыре пункта в одной исполняемой HDL-проверке.

## Зафиксированные допущения

Первая работа по восстановлению RX намеренно использует известные опорные значения вместо слепого синхронизатора:

- CFO и фаза корректируются офлайн до старта RTL-testbench;
- символьный тайминг использует известный `matched_filter_sample_start`;

Благодаря этому цепочка достаточно проста, чтобы проверить её раньше, чем следующие блоки введут петли восстановления тайминга и несущей.

## Расширение восстановления тайминга (Lab 5.8b) — что дальше

Децимация с фиксированной фазой выше предполагает ровно 8 отсчётов на символ. На реальном тракте AD9361 это предположение может отличаться на доли процента, поэтому момент выборки дрейфует по 281-символьному пакету, и BER упирается в ~40 % даже в когерентном loopback (без сдвига несущей). Поэтому в курс добавлена готовая **петля восстановления символьного тайминга Гарднера**, которая отслеживает дрейф:

- убывающий NCO по модулю 1 с 2 стробами на символ, линейный интерполятор (`mu ≈ nco<<2`), **sign-Gardner** детектор ошибки тайминга `e = sgn(y_mid)·sgn(y_on[k]−y_on[k−1])` (не зависит от амплитуды) и ПИ-фильтр петли со степенями двойки в коэффициентах (`k1 = 1/256`, `k2 = 1/4096`) — в петле нет умножителей.

Эталонные модели и RTL, побитово согласованные друг с другом:

| Артефакт | Путь |
| --- | --- |
| Модели float + fixed-point на Python (+ демо) | `python/bpsk_timing_recovery_model.py` |
| Модели float + fixed-point на MATLAB | `matlab/bpsk_timing_recovery_model.m` |
| Скрипт сборки Simulink (блок HDL-Coder MATLAB Function) | `simulink/bpsk_timing_recovery_build_simulink.m` |
| Синтезируемый RTL | `rtl/bpsk_symbol_timing_recovery.v` |
| Генератор векторов | `python/generate_bpsk_timing_recovery_vectors.py` |
| Побитовая HDL-проверка | `tb/tb_bpsk_symbol_timing_recovery.v` |
| Проверка BER всей цепочки (TR против фиксированной фазы) | `tb/tb_bpsk_zynq_ber_timing_recovery.v` |

`bpsk_rx_bit_recovery_chain` выбирает между ними параметром `TIMING_RECOVERY` (0 — фиксированный сэмплер этой работы, 1 — петля Гарднера); runtime-мост AD9361 ставит его в 1. Запуск `python/bpsk_timing_recovery_model.py` печатает таблицу BER float / fixed-point / фиксированная фаза на пакете с дрейфом — обе модели восстановления тайминга достигают BER 0 там, где децимация с фиксированной фазой не справляется.
