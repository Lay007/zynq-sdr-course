# Лабораторная 8.2 — Оценка и коррекция фазового смещения

## Цель

Научиться компенсировать постоянный поворот QPSK-созвездия после устранения частотного рассогласования.

## Что выполняется

В работе студент:

1. генерирует QPSK-сигнал;
2. вносит постоянное фазовое смещение;
3. оценивает фазу слепым методом четвёртой степени;
4. уточняет фазу decision-directed методом;
5. сравнивает EVM и BER до/после коррекции.

## Результат

После выполнения работы должны быть получены:

- constellation plot до коррекции;
- constellation plot после blind correction;
- constellation plot после decision-directed refinement;
- график сравнения EVM;
- metrics JSON.

## Что приложить к отчёту

- true phase offset;
- blind phase estimate;
- decision-directed estimate;
- EVM/BER до и после;
- объяснение ambiguity `pi/2`;
- инженерный вывод.

### Модель фазы

После коррекции частоты несущей может остаться постоянный сдвиг фазы:

```text
r[n] = s[n] * exp(j*phi0) + noise[n]
```

Он поворачивает всё созвездие на `phi0`.

### Слепая оценка фазы QPSK

Для QPSK операция 4-й степени приблизительно убирает данные символов:

```text
phase_est = angle(mean(r[n]^4)) / 4
```

У этого оценщика есть неоднозначность `pi/2`. В реальном приёмнике неоднозначность разрешается дифференциальным кодированием, известной преамбулой, пилотами или кадровой синхронизацией.

### Уточнение по решениям

После грубой коррекции фазы принимаются решения по ближайшим точкам QPSK. Затем остаточная фаза оценивается между принятыми символами и «нарезанными» решениями:

```text
phase_dd = angle(sum(conj(decision[n]) * r[n]))
```

Это полезно, когда созвездие уже достаточно близко к идеалу, чтобы большинство решений были верны.

### Метрики

| Метрика | Смысл |
|---|---|
| истинный сдвиг фазы | намеренно введённый поворот |
| слепая оценка фазы | оценка фазы методом 4-й степени |
| оценка фазы по решениям | уточнённая суммарная оценка |
| ошибка фазы | оценка минус истинная фаза |
| EVM до | ошибка созвездия до коррекции |
| EVM после слепой | ошибка после коррекции 4-й степенью |
| EVM после по решениям | ошибка после уточнения |
| BER до/после | качество решений до/после коррекции |

### Типичные ошибки

| Ошибка | Симптом | Исправление |
|---|---|---|
| неверный знак фазы | созвездие поворачивается дальше | изменить знак коррекции |
| игнорируется неоднозначность `pi/2` | созвездие отображается на неверные биты | использовать преамбулу или дифференциальное кодирование |
| уточнение по решениям стартует слишком рано | неверные решения смещают оценку | сначала выполнить грубую коррекцию |
| CFO всё ещё присутствует | оценка фазы дрейфует | корректировать CFO до сдвига фазы |
| малый SNR | оценка фазы зашумлена | усреднять больше символов или использовать пилоты |

### Чего ожидать

Запуск по умолчанию (4096 символов QPSK, сдвиг фазы 0,70 рад = 40°, шум 0,055 rms, seed 82):

```text
True phase offset: 0.700000 rad
Blind phase estimate: 0.699895 rad
Decision-directed total estimate: 0.700102 rad
Blind phase error: -0.000105 rad
Decision-directed phase error: 0.000102 rad
EVM before: 69.026 %
EVM after blind: 7.833 %
EVM after decision-directed: 7.833 %
BER before: 2.917480e-02 (239/8192)
BER after blind: 0.000000e+00 (0/8192)
BER after decision-directed: 0.000000e+00 (0/8192)
```

- **Поворот на 40° уже вызывает ошибки (BER 2,9 %)**, потому что точки лежат лишь в 5° от границ решений на 45°, и шум переталкивает часть из них.
- **Слепая оценка 4-й степенью точна до 0,0001 рад**, а шагу по решениям исправлять нечего; EVM после обоих — уровень шума (7,8 %).
- **Оценка однозначна лишь в пределах ±π/4 (±45°).** 0,70 рад выбраны внутри этого интервала намеренно. Что происходит за его пределами — в упражнении 1.

!!! note "Исправлено в сентябре 2026"
    До этого работа вычисляла `angle(mean(r⁴))/4` без смены знака среднего (для этих точек QPSK `s⁴ = −1`), из-за чего каждая оценка была смещена на π/4, и использовала 0,82 рад — вне однозначного интервала. Прогон сообщал BER 0,25 «после коррекции».

### Упражнения

1. Задайте `phase_offset_rad` = 0,82 (47°). Слепая оценка становится 0,82 − π/2 = −0,75 рад, скорректированное созвездие повёрнуто на четверть оборота, а BER подскакивает до 0,5, хотя созвездие выглядит идеально. Почему оценщик 4-й степени никогда не отличит 0,82 от −0,75 и как это исправляют известная преамбула или дифференциальное кодирование (см. [Лабораторную 8.7](lab-8-7-snr-vs-ber-traps.md))?
2. Увеличивайте шум, пока оценка по решениям не станет хуже слепой. Почему оценщик по решениям деградирует быстрее при малом SNR?
3. Оцените фазу только по первым 64, 256 и 1024 символам. Как ошибка оценки зависит от числа символов?
