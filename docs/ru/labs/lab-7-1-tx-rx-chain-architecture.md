# Лабораторная 7.1 — Архитектура TX/RX-тракта

## Цель

Спроектировать полный SDR-тракт передачи и приёма до реализации в коде или аппаратуре: от формирования сигнала до расчёта метрик.

## Что выполняется

В работе студент:

1. строит блок-схему TX/RX-тракта;
2. определяет интерфейсы между блоками;
3. задаёт sample-rate plan;
4. задаёт frequency plan;
5. выбирает loopback-режим и метрики проверки.

## Результат

После выполнения работы должны быть получены:

- архитектурная схема тракта;
- таблица стадий обработки;
- таблица частот и sample rates;
- перечень форматов данных;
- план проверки тракта.

## Что приложить к отчёту

- схему TX/RX chain;
- таблицу stage/purpose/input/output;
- frequency-plan check;
- data-format table;
- инженерный вывод о рисках реализации.

## Подробная техническая часть
### Практический вопрос

> Какие блоки нужны между сформированными отсчётами основной полосы и измеренными метриками приёмника и каковы интерфейсы между ними?

### Эталонная архитектура

```mermaid
flowchart LR
    TXSRC[Источник TX] --> SHAPE[Формирование импульса / TX FIR]
    SHAPE --> TXMIX[Микшер TX / DUC]
    TXMIX --> TXIF[Интерфейс TX / AXIS]
    TXIF --> RF[RF-фронтенд]
    RF --> RXIF[Захват RX / файл IQ]
    RXIF --> RXMIX[Микшер RX / DDC]
    RXMIX --> RXFIR[RX FIR / дециматор]
    RXFIR --> METRICS[FFT / SNR / EVM / BER]
```

### Таблица архитектуры

| Этап | Назначение | Вход | Выход | Главный риск |
|---|---|---|---|---|
| Источник TX | генерация тона/символов/кадра | параметры | комплексная основная полоса | неверная амплитуда или структура кадра |
| TX FIR | формирование спектра | комплексные отсчёты | отфильтрованные отсчёты | слишком широкая полоса / ISI |
| Микшер TX / DUC | смещение сигнала в основной полосе | основная полоса | сдвинутый сигнал | неверный знак или наложение |
| Интерфейс TX | формат для FPGA/RF | отсчёты в Q-формате | поток | выравнивание отсчётов |
| RF-фронтенд | преобразование в RF | цифровой поток | RF-сигнал | перегрузка / неверный LO |
| Захват RX | запись IQ | RF-сигнал | файл IQ | отсутствие метаданных |
| Микшер RX / DDC | перенос канала на DC | отсчёты IQ | канал основной полосы | частотная ошибка |
| RX FIR/дециматор | выбор канала | основная полоса | основная полоса с меньшей частотой | наложение |
| Метрики | проверка цепочки | обработанный сигнал | числа/графики | неверное выравнивание эталона |

### План частот дискретизации

```text
Fs источника TX -> Fs формирования TX -> Fs DUC -> Fs ЦАП RF
Fs АЦП RX -> Fs DDC -> Fs после децимации -> Fs метрик
```

Каждое изменение частоты дискретизации должно иметь обоснование антиалиасинга или антиимиджа.

### Проверка частотного плана

Цепочка согласована, если:

```text
expected_rx_offset = TX_LO + TX_baseband_offset - RX_LO
DDC_shift ≈ -expected_rx_offset
```

После DDC полезный сигнал должен быть около DC.

### Порядок валидации

4. RF-кабельный loopback с ослаблением.

### Упражнения

1. Для выбранного сигнала заполните план частот дискретизации и для каждой смены частоты назовите лабораторную из таблицы выше, которая показывает, что происходит без фильтра против наложения или против зеркальных компонент.
2. Какие этапы можно проверить на шаге 1 порядка валидации (чистая симуляция), а какие — только на шаге 4 или 5? Для каждого назовите один вид отказа, который ранние шаги не покажут.
3. Запишите, откуда блок метрик получит опору по фазе и таймингу. Если он использует известные переданные символы, укажите какие (только преамбулу или весь кадр) и что это делает с BER, который вы сообщаете.
