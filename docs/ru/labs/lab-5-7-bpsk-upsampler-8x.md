# Лабораторная 5.7 — BPSK-повышающий дискретизатор символов 8x

## Цель

Вставить явный мост между частотами — между BPSK-маппером символов и RRC TX FIR, работающим на частоте отсчётов.

Новый блок принимает один отсчёт Q1.15 на символьной частоте и выдаёт поток `8x` с вставленными нулями (zero-stuffing), нужный формирующему фильтру:

```text
BPSK-маппер -> 8x upsampler / zero-stuffer -> RRC TX FIR -> будущий ЦАП / RF-тракт
```

## Почему этот блок важен

Маппер символов и TX FIR по природе работают на разных эффективных частотах:

- выход маппера: один комплексный символ за символьный период;
- вход TX FIR: один комплексный отсчёт за каждый такт FPGA в домене частоты отсчётов.

Без явного блока вставки нулей маппер невозможно подключить к формирующему фильтру в детерминированной RTL-цепочке.

## Контракт интерфейса

| Сигнал | Смысл |
|---|---|
| `in_valid` | источник выставляет один комплексный символ Q1.15 |
| `in_ready` | upsampler может принять следующий символ |
| `out_valid` | доступен один выходной отсчёт на частоте отсчётов |
| `out_i`, `out_q` | первый отсчёт — символ, следующие `SPS-1` отсчётов — нули |

Блок держит `out_valid` высоким на всё `8`-отсчётное расширение каждого принятого символа.
