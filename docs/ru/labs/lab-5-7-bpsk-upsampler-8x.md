# Лабораторная 5.7 — BPSK-повышающий дискретизатор символов 8x

## Цель

Вставить явный мост между частотами — между BPSK-маппером символов и RRC TX FIR, работающим на частоте отсчётов.

Новый блок принимает один отсчёт Q1.15 на символьной частоте и выдаёт поток `8x` с вставленными нулями (zero-stuffing), нужный формирующему фильтру:

```text
BPSK-маппер -> 8x upsampler / zero-stuffer -> RRC TX FIR -> будущий ЦАП / RF-тракт
```

## Почему этот блок важен

Маппер символов и TX FIR по природе работают на разных эффективных частотах:

- выход маппера: один комплексный символ за символьный период;
- вход TX FIR: один комплексный отсчёт за каждый такт FPGA в домене частоты отсчётов.

Без явного блока вставки нулей маппер невозможно подключить к формирующему фильтру в детерминированной RTL-цепочке.

## Контракт интерфейса

| Сигнал | Смысл |
|---|---|
| `in_valid` | источник выставляет один комплексный символ Q1.15 |
| `in_ready` | upsampler может принять следующий символ |
| `out_valid` | доступен один выходной отсчёт на частоте отсчётов |
| `out_i`, `out_q` | первый отсчёт — символ, следующие `SPS-1` отсчётов — нули |

Блок держит `out_valid` высоким на всё `8`-отсчётное расширение каждого принятого символа.

## Чего ожидать

```text

```

2248 = 281 x 8. Блок вставляет нули: символ выходит на фазе 0, следующие 7 выходных отсчётов — нули, и `in_ready` опущен на эти 7 тактов. RRC-фильтр из Lab 5.6 превращает эти импульсы с нулями в сформированный сигнал.

Раннер курса генерирует векторы, компилирует, запускает симуляцию и считает ошибкой любую строку `FAIL` или ненулевой код выхода симулятора:

## Упражнения

Каждое упражнение ниже — намеренная мутация RTL в одну строку. Внесите её, запустите testbench, прочитайте сообщения и верните файл (`git checkout -- <file>`). Приведённые выводы получены на Icarus Verilog 12.0.

1. Укоротите счётчик на один: `if (phase == SPS - 2)`. Testbench сообщает 786 ошибок. Первая — `out=(32767,0) expected=(0,0) idx=7` (следующий символ пришёл на отсчёт раньше), последняя — `out_valid=0 expected=1 idx=2247` (поток закончился раньше). Ошибка на единицу в счётчике проявляется как периодическое смещение, а не как случайная ошибка.
2. Почему вставка нулей, а не удержание (повтор символа 8 раз)? Опишите, что удержание делает со спектром до RRC-фильтра.
3. При вставке нулей средняя мощность на выходной отсчёт падает в 8 раз. 65 коэффициентов TX в `rtl/bpsk_rrc_tx_fir_taps.mem` в сумме дают около 2.85 (близко к корню из 8), наибольший коэффициент — 0.387. Объясните, откуда такое масштабирование и какой запас оно оставляет до полной шкалы Q1.15.
