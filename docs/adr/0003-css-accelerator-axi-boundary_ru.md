# ADR 0003: Разделение потоковой и управляющей плоскостей CSS-ускорителя

[English version](0003-css-accelerator-axi-boundary.md)

**Статус:** Принято

**Дата:** 2026-08-26

**Ответственные:** Сопровождающие репозитория

## Контекст

Компактному SF7-детектору нужна граница PS/PL для Zynq, совместимая с DMA,
видимая из ПО и сохраняющая AXI backpressure. Передача каждого отсчёта через
AXI-Lite была бы медленной, а выдача результата только через AXI-Lite привязала
бы всех потребителей к программному polling.

## Решение

Использовать AXI4-Stream для упакованных входных Q1.15-отсчётов и одного
атомарного 256-битного пакета результата. AXI4-Lite используется для
идентификации, управления/статуса, снимка последнего результата, счётчиков и
IRQ. В учебном top-level все интерфейсы находятся в одном тактовом домене, а
CDC и преобразование ширины относятся к системному block design.

## Рассмотренные варианты

| Вариант | Сложность | Совместимость с DMA | Наблюдаемость из ПО | Решение |
|---|---:|---:|---:|---|
| AXI-Stream на входе/выходе и AXI-Lite для статуса | Средняя | Высокая | Высокая | Принято |
| AXI-Stream на входе, результат только через AXI-Lite | Низкая | Средняя | Высокая | Отклонено |
| Отсчёты и результат только через регистры AXI-Lite | Низкая в RTL / высокая в ПО | Низкая | Высокая | Отклонено |

## Последствия

- Backpressure потока не приводит к потере результата.
- ПО может прочитать последний результат, не забирая выходной поток.
- Фиксированная группировка по 128 beat остаётся явной; ошибка TLAST является
  диагностикой, а не механизмом повторной пакетной синхронизации.
- Для узкого DMA/interconnect может понадобиться преобразователь ширины
  256-битного результата.
- Полная интеграция PS7, назначение адресов, выбор CDC и timing платы остаются
  системной работой.
